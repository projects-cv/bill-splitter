# Bill Splitter

Bill Splitter is a web application that helps you split bills easily among friends. It allows you to add items to a bill, mark who ate what, and automatically calculates the total amount each person owes.

## Features

- Add multiple items with prices to a bill
- Assign items to specific people
- Track who ate what
- Automatically calculates the total amount for each person
- Clean and simple user interface

## Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd bill-splitter
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm start
   ```

4. Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.

## Usage

1. Enter the total bill amount
2. Add the names of the people splitting the bill
3. Add each item with its price and the person who consumed it
4. The app will automatically calculate the total for each person

## Development

This project was created with Vite and React.

To run tests:
```bash
npm test
```

To build the project for production:
```bash
npm run build
```
